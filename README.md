# 🧠 Interactive Web Quiz

A responsive Quiz Application built using HTML, CSS, and JavaScript.

## 🚀 Features

- Multiple Choice Questions
- 30-Second Timer
- Progress Bar
- High Score (Local Storage)
- Dark Mode
- Random Questions
- Responsive Design
- Confetti Animation
- Sound Effects
- Quiz Statistics
- Restart Quiz

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage
- Canvas Confetti
